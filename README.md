# Kinebrick Studio releases

Downloads for **Kinebrick Studio**, an editor and simulator for LEGO Technic and Great Ball
Contraption models. Get the latest version from the [Releases](../../releases) page:

- **Windows:** `…-windows-x86_64-setup.exe` (installer) or `…-windows-x86_64.zip` (portable).
- **macOS:** `…-macos-universal.dmg`. It isn't notarized, so the first time, right-click the app
  and choose *Open*.
- **Linux:** `…-linux-x86_64.tar.gz`.

This repository holds only the build workflow; the source is developed elsewhere.
